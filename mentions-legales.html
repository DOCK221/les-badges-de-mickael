Les Badges de Mickael — projet AMICAP33.
Site destiné à faciliter l’accès aux secours pour les personnes en situation de handicap.

Hébergement

Le code source est publié sur GitHub. L’hébergement public peut être assuré par GitHub Pages, Netlify ou un autre hébergeur. Lorsque le site est en ligne, le trafic est servi en HTTPS.

Propriété intellectuelle

Les textes, le logo et les éléments graphiques du projet Les Badges de Mickael sont protégés. Toute reproduction non autorisée est interdite.

Responsabilité

Le site fournit des informations destinées à aider en cas d’urgence. Il ne remplace pas les services de secours officiels (15, 18, 112, 17). En cas de danger immédiat, composez ces numéros.

Données personnelles

Le traitement des données est décrit dans la politique de confidentialité.
